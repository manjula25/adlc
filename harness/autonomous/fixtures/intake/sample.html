SDIAS Operations Hub

A dashboard for monitoring and managing service delivery operations.

Features

  • Real-time ticket queue with priority sorting
  • Agent workload heatmap
  • SLA breach alerts with escalation rules
  • Export to CSV / PDF

User Roles

Supervisor and Agent roles. Supervisors see all queues; Agents see only their assigned tickets.

Tech Notes

Next.js frontend, Supabase backend, real-time updates via Supabase subscriptions.
